# Historical EM evidence

Keep concise experiment summaries here. Bulky reports and arrays are linked to
the exact Git revision that recorded them; they are not runtime inputs or new
baselines. Failures and qualification limits remain in each summary.

The September 12 archive preserves every original file byte-for-byte, with
[hashes and source identity](/scratch/gpfs/CRYOEM/gilleslab/em_work/codex/em_evidence_archive_20260912/manifest.json).
To recover a report locally, use `git show <revision>:<path>` with the revision
and path in its link. Later experiments should store payloads outside the source
tree and retain a short summary, source identity and reproduction instructions.
